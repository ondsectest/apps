Save and Done are enabled even when nothing has changed

IssueSettings, LanguagesVivo 60e, Android

Steps to reproduce

  1. Open Settings and tap Languages.
  2. Without changing anything, look at Save.
  3. Tap Add more.
  4. Without selecting a new language, look at Done.

What happens

  • Save is enabled on Languages even though no language was added or removed.
  • Done is enabled on Select languages even though no new language was selected.
  • Tapping either one looks like an action was taken, but nothing changed.

What was expected

  • Save stays disabled until the languages differ from what is saved: a language added or one deselected.
  • Done stays disabled until at least one new language is selected.
  • Leaving without changes is already covered by Back.

Save and Done turn on only when something changed

ImprovementSettings, LanguagesVivo 60e, Android

Languages

  • Save is disabled when the screen opens.
  • It turns on when a language is deselected or a new one is added from Add more.
  • If the change is undone, for example the same language is ticked again, Save turns off again.

Select languages (Add more)

  • Done is disabled until at least one new language is selected.
  • Deselecting it again turns Done off. Back leaves without changes.
  • Languages added with Done show a small New tag on the Languages screen until saved.

Why it is better

  • The button state tells the truth: it is only active when there is something to save.
  • No taps that look like they did something but did nothing.
