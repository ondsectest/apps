IssueSnippetsVivo 60e, Android

Steps to reproduce

  1. From Home, tap Snippets at the bottom.
  2. Tap + to add a new snippet.

What happens

  • The Add snippet dialog opens, but no field has the cursor.
  • The keyboard does not open.
  • The user has to tap the Snippet field before they can start typing.

Why it matters

  • The dialog is a single-task form: typing a snippet is the only thing to do there.
  • An extra tap every time a snippet is added adds friction and slows the user down.

Cursor ready in the Snippet field, keyboard open

ImprovementSnippetsVivo 60e, Android

What changes

  • When + is tapped, the cursor is placed in the first field, Snippet.
  • The keyboard tray opens automatically, so the user can start typing straight away.
  • Everything else stays the same: the placeholders, Cancel, and Add staying disabled until both fields have text.

Why it is better

  • One tap fewer every time a snippet is added.
  • The form feels ready, because there is nothing else to do on it.
  • Works well with dictation too: the user can start speaking right away.
