# Wispr Flow

UX prototypes and findings for [Wispr Flow](https://wisprflow.ai), organised by the platform and device they were found on. Open a folder to see its prototypes.

| Platform | What is inside |
| --- | --- |
| [Android (Vivo 60e)](./Android%20Vivo%2060e) | Thirteen prototypes, one improvement request and one UI bug report from the Android app: a shorter Report an issue journey, a clearer admin-locked setting, consistent punctuation, Back and Close in confirmation dialogs, the Add Wispr Flow to LinkedIn help animation that goes dark after locking the phone, Deselect all and Select all for languages, a smoother Edit Profile dialog, a Share feedback screen that is ready to type, naughty strings handled safely in Edit Profile, a slower, readable LinkedIn help animation, a Snippets error that does not say which field is too long, an Add snippet dialog with the cursor ready in the first field, Save and Done on Languages that turn on only when something changed, stretched words like "whaaaat" lost in Very Casual style, and two off toggles in different colours, so one looks on. |

More platforms, such as web, Mac and Windows, will be added as their own folders.

Prototypes by Santhosh Tuppad.
