# Wispr Flow

UX prototypes and findings for [Wispr Flow](https://wisprflow.ai), organised by the platform and device they were found on. Open a folder to see its prototypes.

| Platform | What is inside |
| --- | --- |
| [Android (Vivo 60e)](./Android%20Vivo%2060e) | Nine prototypes from the Android app: a shorter Report an issue journey, a clearer admin-locked setting, consistent punctuation, Back and Close in confirmation dialogs, the Add Wispr Flow to LinkedIn help animation that goes dark after locking the phone, Deselect all and Select all for languages, a smoother Edit Profile dialog, a Share feedback screen that is ready to type, and long names kept to one line. |

More platforms, such as web, Mac and Windows, will be added as their own folders.

Prototypes by Santhosh Tuppad.
