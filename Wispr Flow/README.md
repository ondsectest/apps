# Wispr Flow

UX prototypes and findings for [Wispr Flow](https://wisprflow.ai), organised by the platform and device they were found on. Open a folder to see its prototypes.

| Platform | What is inside |
| --- | --- |
| [Android (Vivo 60e)](./Android%20Vivo%2060e) | Seventeen prototypes, one improvement request and one UI bug report from the Android app: a shorter Report an issue journey, a clearer admin-locked setting, consistent punctuation, Back and Close in confirmation dialogs, the Add Wispr Flow to LinkedIn help animation that goes dark after locking the phone, Deselect all and Select all for languages, a smoother Edit Profile dialog, a Share feedback screen that is ready to type, naughty strings handled safely in Edit Profile, a slower, readable LinkedIn help animation, a Snippets error that does not say which field is too long, an Add snippet dialog with the cursor ready in the first field, Save and Done on Languages that turn on only when something changed, stretched words like "whaaaat" lost in Very Casual style, two off toggles in different colours, so one looks on, search for transcript history by words and dates, a Play Store Terms of Service link that opens a 404 because of a trailing full stop, a silent dictation that saves an empty transcript, and form fields that stop at their maximum length instead of failing after. |
| [Wispr Flow Desktop on MacBook Pro](./Wispr%20Flow%20Desktop%20on%20MacBook%20Pro) | One prototype from the desktop app on a MacBook Pro (macOS): a Delete account dialog that warns about an active Pro plan before it is cancelled with no refund. |

## All prototypes in one page

[`master-artifacts.html`](./master-artifacts.html) brings every prototype and report together in one self-contained page, with a sidebar on the left to move between them and Previous and Next buttons. Download it and open it in any browser.

More platforms, such as web and Windows, will be added as their own folders.

Prototypes by Santhosh Tuppad.
