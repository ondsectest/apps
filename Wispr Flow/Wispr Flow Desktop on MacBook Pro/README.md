# Wispr Flow Desktop on MacBook Pro

UX prototypes and bugs found while testing the Wispr Flow desktop app on a MacBook Pro (macOS). Each folder will hold a small, working page or report for one finding.

| Prototype | What it improves |
| --- | --- |
| [Delete Account Warns About an Active Pro Plan](./Delete%20Account%20Warns%20About%20an%20Active%20Pro%20Plan) | The Delete account dialog says nothing about an active Pro plan, which the help docs say is cancelled immediately with no refund. The improvement warns about the plan, offers Manage plan and Contact support, and needs a tick box before Delete. |

Prototypes by Santhosh Tuppad.
